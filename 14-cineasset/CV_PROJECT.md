# CineAsset — Cinema Asset & Maintenance Desktop App

**Client:** Al Arabia Cinema

## One-line summary
Electron desktop app for cinema asset and maintenance tracking — React renderer, MongoDB, JWT sessions, audit log, and Windows production builds.

## Tech stack
- **Desktop:** Electron, React, TanStack Query, React Router, Vitest
- **Data:** MongoDB (Mongoose), local-first IPC architecture
- **Features:** Audit log, CSV export, soft delete, SMTP settings, rate-limited auth

## Key features
- Branch, hall, asset, supplier, and maintenance management
- Admin user management with role-based branch access
- Audit log with CSV export; attachment handling via app userData
- Windows desktop distribution with production build pipeline

## CV bullet points
- Built **CineAsset**, an Electron + React desktop app for cinema asset and maintenance tracking with MongoDB and JWT-secured IPC.
- Delivered admin RBAC, audit logging, CSV exports, and Windows production builds for cinema operations teams.
- Implemented local-first architecture with rate-limited auth and secure session handling.
