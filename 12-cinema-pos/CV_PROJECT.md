# Cinema Concession POS — Enterprise Platform (Al Arabia Cinema)

## One-line summary
Enterprise cinema concession POS for Renaissance Cinemas — React Admin, Flutter POS, Flutter Branch Manager, Laravel API, PostgreSQL, offline-first branch sync, and partner integration APIs.

## Tech stack
- **Backend:** Laravel, PHP 8.3, PostgreSQL, Redis, Sanctum, domain-driven modules
- **Admin:** React 19, TypeScript, TanStack Query, Tailwind CSS, Vitest
- **Mobile:** Flutter POS (offline SQLite/Isar + SyncQueue), Flutter Branch Manager, FCM
- **Architecture:** 8–10 microservices target, OpenAPI partner APIs, Docker, GitHub Actions, observability
- **Docs:** 1,300+ pages architecture/design specification

## Key features
- Multi-client platform: HQ admin, floor POS terminals, branch manager mobile
- Offline-first POS sync: head office → branch → terminal with conflict handling
- Catalog, inventory, purchasing, warehouse transfers, business days, shifts
- RBAC, bilingual EN/AR, partner integration APIs with OpenAPI documentation
- Production Docker stack, CI/CD, and microservices migration roadmap
