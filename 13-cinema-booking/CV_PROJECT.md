# Cinema Booking — Ticketing Platform (RNS Cinemas)

## One-line summary
Cinema booking platform with Symfony 7 and Spring Boot API backends, Angular 19 frontend, MongoDB, and Redis — live at booking-app.rnscinemas.com.

## Tech stack
- **Backend:** Symfony 7.2, Spring Boot 3.3, PHP 8.3+, Java 21, JWT auth
- **Frontend:** Angular 19
- **Data:** MongoDB (Doctrine ODM), Redis cache
- **Deploy:** Docker Compose, cPanel/VPS production deploy scripts

## Key features
- Dual backend parity: Symfony and Spring Boot API ports
- JWT authentication, health checks, production cPanel deployment
- Angular SPA with Docker-based local development stack
